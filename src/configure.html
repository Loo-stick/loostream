Installer LooStream

Quelques étapes pour générer ton lien d'installation Stremio / Nuvio.

Es-tu l'hébergeur de ce LooStream ?
🔒 Le proxy local (relais serveur) est réservé à l'hébergeur : il se débloque avec la clé propriétaire ci-dessous. Sans elle, l'option reste masquée — et même en trafiquant le lien, le serveur refuse le local (il retombe sur les modes autorisés, et le proxy exige la clé d'accès).

La plupart des gens laissent ce champ vide et continuent.

Comment les flux te sont livrés

🚀 Direct — sans proxy Recommandé

Stremio lit directement depuis les CDN. Zéro bande passante serveur. Les flux qui exigent un proxy (NetMirror, hôtes bloqués) ne sont pas proposés.

☁️ MediaFlow Partagé / public

Ce qui peut se lire en direct passe en direct (0 bande passante) ; le reste passe par un MediaFlow externe. Idéal pour un usage partagé.

🏠 Proxy local Hébergeur

Ton serveur relaie ce qui ne passe pas en direct. Couvre le plus de sources. Protégé par la clé d'accès. Débloqué par la clé propriétaire (étape 1).

⚠️ En mode local, tout le trafic vidéo non-direct passe par ton serveur (un 4K ≈ 25 Mbps). À réserver à l'hébergeur, non recommandé en public.

Tes clés — privées, jamais partagées
🔑 La clé TMDB résout titres, saisons et épisodes. Gratuite en 2 min sur themoviedb.org → Paramètres → API. Les deux formats marchent : « API Key » (v3) ou « API Read Access Token » (v4).

📦 Installer MediaFlow Proxy

Sur nakastream.tv (connecté — un email fictif suffit), lance « Connecter une TV / un appareil », copie le code affiché et colle-le ici. Ça active nakastream juste pour toi.

Qualités, tri & langues
« Inconnu » = sources en « HD » sans résolution mesurée (Movix, Coflix…). Décoche-le pour aussi les exclure.
Souple : relâche la langue mais GARDE tes exclusions de qualité. Strict : liste vide plutôt qu'un flux non voulu (ex. que du 360p sur un film pas encore sorti).

« Langue puis qualité » : ton ordre de langues d'abord, meilleure qualité en tête de chaque langue. « Qualité puis langue » : la meilleure qualité remonte toutes langues confondues.

  • 1⋮⋮MULTIVF + VO
  • 2⋮⋮VFVersion française
  • 3⋮⋮VOSTFRVO sous-titrée FR
  • 4⋮⋮VOVersion originale

Décoche « Proposer des sous-titres » pour que LooStream disparaisse complètement du sélecteur de sous-titres de ton lecteur.

Dernière étape — ton pseudo
👤 Le pseudo est obligatoire : il permet au support de t'identifier si tu signales un souci. Sans lui, l'addon ne renvoie aucun flux.

Lettres, chiffres, espace, _ . - — 24 caractères max.
