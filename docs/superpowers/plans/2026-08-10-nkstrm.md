# Intégration nkstrm — Plan d'implémentation

> REQUIRED SUB-SKILL: superpowers:executing-plans. Étapes en `- [ ]`.

**Goal:** Ajouter nkstrm comme source opt-in par utilisateur (pairing par code), avec sous-titres FR/EN.

**Architecture:** Nouveau scraper `src/scrapers/nkstrm.ts` (search→match tmdb→streaming/source, Bearer token). Endpoint serveur `/api/nkstrm/claim` pour le pairing. Champ `nkstrmToken` par user. Gestion 401 = entrée informative non-bloquante. Subs via la ressource `/subtitles`.

**Tech:** TS strict, axios, cache existant. Gabarit = `src/scrapers/nabistream.ts`.

## Global Constraints
- Aucun `git push` sans l'aval de Stick. Commits locaux OK. `npm run build` = vérif tsc.
- Ne jamais logguer le token en clair (logbuffer masque déjà, mais éviter les console.log du token).
- Rétro-compat base64 (champ absent = OK). Token per-user, jamais partagé.
- Résolution au **stream-time** (token `exp` court). Ne PAS utiliser `by-tmdb` (cassé) — `browse/search` + match `tmdbId`.
- Déployer pour que Stick teste ; ne rien pousser.

## Task 1 — Scraper `src/scrapers/nkstrm.ts`
**Files:** Create `src/scrapers/nkstrm.ts`
- [ ] `NkstrmStream { url; quality; language; server:'nkstrm'; subtitles:{lang;url}[] }` + `class NkstrmAuthError extends Error`.
- [ ] `nk(token)` = axios instance, base `https://nkstrm.tv/api/v1`, header `Authorization: Bearer <token>`, UA + Referer, timeout 12s, retry DNS (1 retry sur ENOTFOUND/EAI_AGAIN).
- [ ] `resolveContentId(token, tmdbId, title, mediaType)` : `GET /browse/search?q=<title>` → `data[].find(c => String(c.tmdbId)===String(tmdbId) && c.mediaType===(series?'tv':'movie'))` → `id` ou null.
- [ ] `getNkstrmStreams(token, tmdbId, mediaType, season?, episode?, title?)` : garde `if (!token || !tmdbId || !title) return []`. Cache `nkstrm:${mode?}:${tmdbId}:${season||''}:${episode||''}` TTL 5 min (`shouldCache: r=>r.length>0`).
  - résout contentId (sinon `[]` silencieux),
  - `GET /streaming/source/<id>` (+ params season/episode si série) → `{url, subtitles, audioTracks}`,
  - **401** → `throw new NkstrmAuthError()`,
  - master absolu `https://nkstrm.tv${url}` ; `language` = 'MULTI' si ≥2 audioTracks sinon 'VF'/'VOSTFR' ; `quality` via probe master (ou 'HD') ; subs = `subtitles.filter(url).map(s=>({lang: iso3(s.lang), url: 'https://nkstrm.tv'+s.url}))`.
- [ ] `npm run build` OK.
- [ ] Test live (token dans /tmp/claim2.json) : script node ad-hoc → Dune 2 (tmdb 693134, title "Dune : Deuxième partie") renvoie 1 flux + 2 subs.
- [ ] Commit `feat(nkstrm): scraper (search+match tmdb -> streaming/source + subs)`.

## Task 2 — Config + endpoint claim (`src/index.ts`)
- [ ] `UserConfig.nkstrmToken?: string` + sanitize dans `parseConfig` (`^[A-Za-z0-9._-]{10,120}$`, sinon undefined) + inclus dans le retour.
- [ ] `POST /api/nkstrm/claim` (jsonBody) : body `{code}` → `POST nkstrm.tv/api/v1/auth/pair/claim {code}` → `{ok:true, token}` (extrait `token`) ou `{ok:false, error:'Code invalide ou expiré'}`. Timeout + retry DNS. Ne loggue pas le token.
- [ ] `npm run build` OK. Test : `curl -XPOST /api/nkstrm/claim -d '{code}'` (avec un code frais fourni par Stick au moment du test) → renvoie un token.
- [ ] Commit `feat(nkstrm): champ config + endpoint /api/nkstrm/claim`.

## Task 3 — Fan-out + 401 + sous-titres (`src/index.ts`)
- [ ] Import `getNkstrmStreams, NkstrmAuthError`. Ajouter `'nkstrm'` à `SOURCE_NAMES` + une source dans le fan-out, gatée `isSourceEnabled('nkstrm') && !!config?.nkstrmToken`, appelée avec `(config.nkstrmToken, info.tmdbId, type, parsed.season, parsed.episode, info.title)`. `.catch` : si `NkstrmAuthError` → poser un flag `nkstrmAuthFailed=true` et renvoyer `[]` ; sinon log + `[]`.
- [ ] Livraison : mapper les résultats nkstrm en flux (comme les autres scrapers à `{url,quality,language,server,subtitles}`) → `deliver(url, {Referer:'https://nkstrm.tv/'}, {forceHls:true}, …)`. Master directable (token) ; repli proxy si besoin.
- [ ] Après le fan-out : si `nkstrmAuthFailed`, **ajouter une entrée informative** en fin de `cleanStreams` : `{name:'nkstrm ⚠️', title:'nkstrm déconnecté\nReconnecte-le dans la configuration.', externalUrl: '<base>/<cfgParam>/configure'}`. Non-bloquant.
- [ ] `handleSubtitles` : ajouter un bloc nkstrm (si `config?.nkstrmToken`) → re-résout via `getNkstrmStreams(...)`, pousse les subs `{id:'nkstrm-<i>-<lang>', url: signUrl(proxied), lang}` (proxifier/​signer comme nabistream/moviebox).
- [ ] `npm run build` OK + déploiement + test bout-en-bout (config avec token → flux nkstrm + subs sur Dune 2).
- [ ] Commit `feat(nkstrm): fan-out + entree informative 401 + sous-titres`.
